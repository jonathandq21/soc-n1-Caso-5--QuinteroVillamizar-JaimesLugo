# SOC Nivel 1: Caso C05 - PagoClaro Fintech S.A.S.

Repositorio técnico correspondiente al caso de estudio de implementación de seguridad defensiva, monitoreo de eventos e integración de servicios ITIL[cite: 1].

## 🚀 Componentes del Proyecto
- **Monitoreo y SIEM :** Despliegue de servidor central y agentes (Linux/Windows), configuración de FIM (Monitoreo de Integridad de Archivos), reglas personalizadas de correlación, SCA y respuestas activas[cite: 1].
- **Protección de Endpoints (Kaspersky EDR/XDR):** Gestión de políticas de control de dispositivos, aislamiento de red, control web y reenvío de alertas en formato CEF vía Syslog[cite: 1].
- **Mesa de Ayuda y CMDB (GLPI Cloud v10):** Gestión automatizada de inventarios, parametrización de SLAs bajo marcos ITIL y trazabilidad de incidentes de seguridad[cite: 1].

## 🛠️ Tecnologías Utilizadas
* **Wazuh** (SIEM & XDR)[cite: 1]
* **Kaspersky Endpoint Security Cloud** (EDR)[cite: 1]
* **GLPI Cloud** (ITSM / ITAM)[cite: 1]
* **Ubuntu Server & Windows** (Entorno de Laboratorio VirtualBox)[cite: 1]
